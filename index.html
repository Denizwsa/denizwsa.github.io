Wsamiaw is built for Minecraft 1.8.9 with Forge. It includes a ViaVersion integration that lets you spoof your protocol version to connect to servers running different versions (requires server-side ViaVersion support).

Yes! Wsamiaw is completely free and open-source. You can download the latest release from GitHub or build it yourself from source.
